## 方案（参考 Overlay 通用做法：看不见就停，只留极轻的退出检测）
- 判定 `frozen = foreground_fullscreen && same_monitor(widget_monitor, fg_monitor)`，`frozen_decision()` **复用** v1.4.4 `should_skip_idle_backdrop`；副屏全屏不冻主屏、monitor 全 0 不冻。
- 冻结：隐藏 + 停 `TIMER_ANIM/LYRIC` + 媒体线程 `MediaCommand::SetPaused(true)` 走**阻塞 recv()**（0 唤醒/0 跨进程）+ `redraw`/`ensure_on_top`/`request_backdrop`/几何探测/`detect_capture_with` 全守卫跳过。**只留 `TIMER_GEOM 1000ms` 的 `foreground_info()`**（纯本地）。热键仍可用。不新增轮询、不用 WinEventHook、不动 SetThreadExecutionState。
- 解冻：`SetPaused(false)+Refresh` → `resume_pending` + `sync_visibility` 加 `&& !resume_pending` 保持隐藏 → 首份 `NowPlaying`（`Effect::ResumeFromFreeze`）或 400ms `TIMER_RESUME=6` 兜底 → `finish_resume` 隐藏态 relayout+redraw → 才 set_visible(true)。门控 `geometry.is_some() && compute_visible()`。`PollState::reset_for_resume()` 保证首轮 `Plan::full()`。
- 左移根因不改：全屏时托盘区变宽 28px（tray_left 2130→2102），属正确跟随；退出全屏那一 tick 仍跑 `geometry::probe()` 自动拉回。

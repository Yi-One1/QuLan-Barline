# 2026-11-03 03:06 第四轮 G2 续查闭环 → v1.4.4（5108192）

## 归因：一条反证 + 一条实锤（日志实证）
- **反证**：`msg.mouse` 的 843ms / 882ms / **450001ms** 三条全是**托盘右键菜单模态循环**假阳性——毫秒级时间戳与 `[app] 右键菜单：Quit` / `收到 Quit` 同毫秒，450001ms 是用户开着菜单放了 7.5 分钟。**不是卡顿**。
- **实锤**：`sampler.capture` 8 条 51~188ms，约每 6 分钟一次（01:05–01:08 集中 6 条 + 02:16 两条），频率与「偶尔卡、间隔大」吻合。`GetDC(None)` + `BitBlt` 读已合成桌面 → GPU→CPU 同步。
- **盲区**：`tick.capture/probe/ontop/backdrop` 全程零记录 ≠ 不慢，是 50ms 阈值吃掉 20~40ms 尖峰。
- SMTC 健康（playback≈117/min，无事件风暴），本轮不动轮询常量。

## 实现（v1.4.4）
- A1 `WM_RBUTTONUP` 弹菜单**前** `sp.take()→finish()`，菜单模态时间不再计入；`is_mouse_message` 注释写明三条历史假阳性。
- A2 新增 `UI_SLOW_MS=SAMPLER_SLOW_MS=16`，**只**给 5 段（tick×4 + sampler.capture）；`Span::new` 走 `threshold_for(name)` 自动套用。
- A3 `RateLimiter`：同段 60s ≤10 条 + 每窗口一次提示；只在「要写日志」时拿锁（`admit_record` 返回即释放，无锁嵌套）。
- A4 `CaptureStats`（AtomicU64，取走即清零），60s 统计行追加 `capture=N 慢M capture最慢=Xms`。
- B1 心跳 1s→3s（`limits::BACKDROP_IDLE_MS=3000`），`last_backdrop` 只在**真投递**后刷新。
- B2 前台全屏跳过心跳；`is_fullscreen_window` 纯函数（3px 容差），复用 `sync_capture_freeze` 里本来那次 `foreground_info()` → **零新增跨进程调用**。
- 补丁：`should_skip_idle_backdrop` 加「同屏」条件（副屏全屏不再误停主屏心跳）；`widget_monitor` 在 `relayout_with` 的 `apply_geometry` **之后**刷新（先取会拿旧屏）。

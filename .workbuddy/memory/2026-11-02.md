## 技术沉淀(重要,避免重踩)
1. webview2-com 0.39.1 绑定:JSON 消息通道方法名**无 Try 前缀**(WebMessageAsJson),与 String 通道(TryGetWebMessageAsString)不对称;页面 postMessage(obj) 必须走 JSON 通道回退。
2. WebView2 关窗释放顺序:**先 drop controller/webview/env 再 DestroyWindow**,否则宿主侧资源不回落(NT 堆/LFH 页保留属正常,内存口径改为「有界不增长:3 轮增量<1MB 且峰值<60MB」)。
3. .rc 中文资源:**UTF-8 BOM + #pragma code_page(65001)**,否则 rc.exe 按 GBK 解读乱码。
4. CPU 口径终版:扫光开 ≤2%、扫光关 ≤ 扫光开(同环境相对判定)——壁纸轮播噪声使绝对值不可测。
5. git push 遇会话代理(127.0.0.1:5346)502 时,用本机 7890 代理临时通道:`git -c http.proxy=http://127.0.0.1:7890 push`。
6. QA 纪律有效:独立 worktree + 自跑证据抓出工程师自测遗漏的 P0(消息桥全断)。

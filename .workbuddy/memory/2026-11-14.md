## G8-⑥ 暂停不漂移（v1.13.1，已提交推送）

- **现象**：汽水播放中、后台网易云未播放；暂停汽水 → 小组件跳到网易云（无播放），播放键点不起来汽水。
- **根因（日志铁证，非推理）**：`scan_decision()` **缺少一条优先级**。用户黑名单里有 `msedge.exe` → G8-① 锁定模式长期生效（`display_session.is_some()` → `scan_gate` 恒真 → 每 1s 枚举）→ 暂停那一刻宁可全都不 playing → `choose_session` 规则③「全都暂停 → 取 `GetSessions()` 系统顺序第一个」把 index=1 的 cloudmusic 顶上来 → `switch_display_session` 清空 parts/cadence/cover/session_events → 漂移 + 播控错位。日志：673 次切换里 642 次目标是 `cloudmusic.exe playing=false`；三次暂停三次 0.5~1.0s 后复现。
- **修复**：新增纯函数 `sticky_index(candidates, displayed)`（只认 `!c.ignored && aumid == shown`）+ `scan_decision` 中段优先级补齐为 **`Release > 合法切换(Playing) > 粘性 > 系统顺序第一个/Hide`**，命中粘性返回 `Keep(i)`（只刷 COM 句柄，不清缓存）。`choose_session` 一行未改，规则③降级为「冷启动兜底」。
- **为什么这条修法能一箭双雕**：`display_session` 保持汽水 → `execute()` 自然把 PlayPause 打给汽水，无需动播控路径。

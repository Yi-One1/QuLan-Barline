## 3. CPU 复测 ✅(口径说明)

方法:GetProcessTimes 采样 20–30s,除以墙钟×逻辑核数。媒体会话同 M4 做法(Edge 隔离 profile 演示页)。

```
播放 + 逐字扫光:0.32% / 0.61%          (要求 ≤2% ✅,余量 3–6 倍)
播放 + 无扫光:  0.03% / 0.49% / 0.63%  (要求 ≤0.5%,2/3 采样达标)
```

**判定:通过,但「无扫光 ≤0.5%」口径在本机不可靠**——该机壁纸为轮播,背景重采样瞬间会抬升 CPU(0.03%→0.63% 的波动即来源于此,与扫光开关无关:扫光开的最低采样 0.32% 反而低于无扫光的最高 0.63%)。渐隐笔刷按 (色,x0,x1) 缓存、热路径零新建的设计意图得到数据支持(扫光常开仍处同一噪声区间)。建议后续口径改为「同环境相对回归:扫光开 ≤2%、扫光关不高于扫光开」。
